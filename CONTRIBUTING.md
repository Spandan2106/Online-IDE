# Contributing to Online IDE

Thank you for your interest in contributing to the Online IDE project! We welcome contributions, bug reports, and feature requests to make this project better for everyone.

---

## 🚀 How to Get Started

### 1. Prerequisites
Ensure you have the following installed locally:
- [Node.js](https://nodejs.org/) (v18+ recommended) or [Bun](https://bun.sh/)
- [Docker](https://www.docker.com/) (optional, required if testing localized compilers for C, C++, Python, etc.)

### 2. Fork & Clone
1. Fork the repository to your GitHub account.
2. Clone your fork locally:
   ```bash
   git clone [https://github.com/YOUR-USERNAME/Online-IDE.git](https://github.com/YOUR-USERNAME/Online-IDE.git)
   cd Online-IDE
